# Launch Checklist

## Purpose

This checklist ensures that all critical elements are in place before you begin active customer acquisition. It covers the product, the offer, the sales assets, the operations, and the compliance requirements.

A launch is not a one-time event. It is the beginning of a sustained outreach effort. This checklist helps you avoid the most common mistakes that cause launches to generate interest without generating revenue.

---

## Launch Checklist

### Product Readiness

- [ ] MVP is deployed and accessible to target users
- [ ] Core workflow has been tested end-to-end with real data
- [ ] At least one real user has completed the full workflow
- [ ] Human review steps are in place for any high-stakes outputs
- [ ] Error handling is in place and tested
- [ ] Basic logging and monitoring are active
- [ ] Data security controls are in place

---

### Offer Readiness

- [ ] Offer description is written in clear buyer language (no technical jargon)
- [ ] Scope is explicitly defined (what is included and what is not)
- [ ] Success criteria are defined and agreed with early users
- [ ] Pricing is set with rationale
- [ ] At least one pricing tier is ready to present
- [ ] Payment method is set up and tested
- [ ] Contract or agreement template is ready (even a simple one-page agreement)

---

### Sales Assets

- [ ] One-pager or pitch deck is ready (1–2 pages maximum)
- [ ] Demo environment is ready (with sample data, not blank)
- [ ] At least one proof point exists: a case study, a pilot result, or a reference customer willing to speak
- [ ] Outreach message is written and reviewed by someone other than you
- [ ] First 20 prospects are identified and contact information is collected
- [ ] Follow-up sequence is defined (what you send after the first call)

---

### Operations Readiness

- [ ] Onboarding process is documented and tested
- [ ] Support channel is defined and staffed
- [ ] Response time commitment is set and communicated
- [ ] Delivery checklist is complete and ready to use
- [ ] Invoicing process is set up
- [ ] Customer data handling process is documented

---

### Legal and Compliance

- [ ] Terms of service or service agreement exist
- [ ] Privacy policy exists (if processing personal data)
- [ ] Data processing agreement template is ready (for regulated customers)
- [ ] Any domain-specific compliance requirements have been reviewed
- [ ] AI disclosure obligation reviewed (where applicable)

---

### Go-to-Market Execution

- [ ] Outreach channel is selected and ready (LinkedIn, email, community)
- [ ] Outreach message is personalized for the first 20 prospects
- [ ] Tracking system is in place (spreadsheet, CRM) to track outreach and responses
- [ ] Discovery call agenda is prepared
- [ ] Calendar link or booking method is ready
- [ ] 30-day conversion milestone is defined

---

### Post-Launch Monitoring

- [ ] Metrics dashboard is set up (see Weekly Metrics Tracker)
- [ ] Weekly review cadence is scheduled
- [ ] Feedback collection process is ready
- [ ] First-customer check-in is scheduled (day 7, day 30)
