# MVP Specification Template

## Purpose

This template helps you define the smallest useful version of your AI product or service before writing any code. It forces clarity about what the MVP must do, what will be done manually, what is out of scope, and what success looks like.

An MVP is not a prototype. It is a real, usable version of the solution that delivers value to one specific user in a real context.

Complete this template before starting to build. If you cannot fill in every section, you are not ready to build yet.
